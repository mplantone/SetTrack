# Set Track

A website that helps you keep track of your sets at the gym.

I built this app because I kept losing count of my sets and wanted a set counter and a stopwatch in one place.

## How It Works

1. After completing your first set, click **Start**. The set counter changes to 1, and the stopwatch starts.
2. Before starting your next set, you can pause the stopwatch or leave it running.
3. After completing the next set, click **Stop**. The set counter increases by 1, and the stopwatch restarts from zero.
4. Repeat these steps for each set. When you finish your exercise, click **Reset** to reset both the counter and the stopwatch.
